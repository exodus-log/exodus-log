# יומן אקסודוס

יומן עצמאי בעברית שעוקב אחרי דניאל פינסקי והסירה **אקסודוס** במרוץ **גולדן גלוב 2026**: הקפת העולם לבד, בלי עצירות, בלי GPS ובלי עזרה מבחוץ.

זה פרויקט עצמאי, לא אתר רשמי של המרוץ ולא של הצוות של דניאל. המספרים הם תמונת מצב מהעדכון האחרון, לא שידור חי. המקורות הרשמיים הם [מעקב המרוץ של YB](https://pro.yb.tl/ggr2026/) ו[הדיווחים היומיים של המרוץ](https://goldengloberace.com/).

**האתר:** [exodus-log.com](https://exodus-log.com)

## איך זה בנוי

אתר סטטי: HTML, CSS ו-JavaScript רגילים, בלי שרת. כל דחיפה ל-`main` עולה לאוויר לבד, בלי שלב בנייה בדרך.

| קובץ | מה יש בו |
|---|---|
| `index.html` | הדף הראשי: ההדמיה כחלון קבוע על כל המסך, ו"המסע" (הגלובוס, הצי, התחזית והסקסטנט) שנפתח מעליה. כל העיצוב של החלון יושב בתוך הקובץ |
| `deep-dive.html` | הניתוח המלא, סטטי לגמרי, בלי JavaScript |
| `assets/data.js` | כל המספרים: מיקום, דירוג, צי, מסלול, מזג אוויר, ונקודת החובה הבאה |
| `assets/v2/deck.js` | מנוע ההדמיה: WebGL, אסטרונומיה, גלים, רוח, זרם, עננים, טבעת המצפן. **נבנה אוטומטית** מ-`assets/deck.js` ועוד תוספות |
| `assets/v2/hud.js` | שורת הנתונים, שלושת השעונים, התוויות שעל הטבעת, המפה הקטנה, התפריט והקול |
| `assets/v2/journey.js` | מרנדר את "המסע" מתוך `data.js`. **נבנה אוטומטית** מ-`assets/front.js` |
| `assets/v2/globe.js`, `assets/v2/sextant.js` | הגלובוס (MapLibre) והסקסטנט: העתקים של המקור שב-`assets/`, בצבעי הדף הנוכחי |
| `assets/v2/journey.css` | הסגנון של "המסע", מעל `assets/front.css` |
| `assets/v2/coast.js` | קו חוף ברזולוציה בינונית, למפת המיקומים הקטנה |
| `src/` | המקורות של הדף הראשי ושל הבנייה: `page.html`, `hud.js`, טלאי המנוע, וכלי הבדיקה. `python3 src/build_site.py` בונה הכול. ראו `src/README.md` |
| `assets/deck.js`, `assets/front.js`, `assets/globe.js`, `assets/sextant.js` | גם הם מקורות: מהם, יחד עם `src/`, נבנים קובצי `v2`. הדף לא טוען אותם ישירות |
| `assets/course.js` | נאפה פעם אחת: קו המסלול הרשמי, נקודות החובה, והיסטוריית הצי מהזינוק |
| `assets/geo/land50.js` | קו החוף העולמי, Natural Earth 1:50m |
| `assets/tiles/earth/` | כדור הארץ: NASA Blue Marble, אריחים מקומיים |
| `assets/vendor/` | MapLibre GL JS, עותק מקומי |
| `assets/fonts/` | הפונטים, תת-קבוצה עברית ולטינית |
| `assets/front.css` | העיצוב של מקטעי "המסע". נטען רק כשפותחים אותו |
| `assets/style.css` | העיצוב של `deep-dive.html` |
| `assets/icons/`, `manifest.webmanifest` | הוספה למסך הבית, כמו אפליקציה |

שלושה כללים לפני שנוגעים בקוד:

- **אין בדף הראשי מספר שכתוב ביד.** כל מספר מגיע מ-`data.js`.
- **כמעט בלי תלות חיצונית.** בלי CDN ובלי פונט מגוגל: הפונטים, MapLibre, קו החוף ואריחי כדור הארץ בזום רחוק יושבים כאן. שני חריגים: בזום קרוב על הגלובוס האריחים מגיעים ישירות מ-NASA GIBS, ו-Cloudflare מוסיפה לדף את סקריפט ספירת הביקורים שלה.
- **סדר הטעינה קבוע:** `data.js`, אחריו `course.js`, ואז `v2/deck.js` ו-`v2/hud.js` עם `defer`. "המסע" וכל מה שהוא צריך נטענים רק כשפותחים אותו.

## איך הדף הראשי בנוי

ההדמיה היא חלון קבוע על כל המסך, כדי שגרירה באצבע תוכל להטות את המבט לכל כיוון, גם אל מתחת למים. הטקסט יושב ישר על התמונה: שורת נתונים, שלושה שעונים, מספרי המרוץ, ומפה קטנה שפותחת את "המסע" מעל החלון. על המים שוכבת טבעת מצפן של שנתות, עם נוצת רוח, חץ זרם וקשתות גל. התרחקות עד הסוף פותחת את הגלובוס.

כל מה שב-`assets/v2/` ו-`assets/v2n/`, ו-`index.html` עצמו, נבנים אוטומטית ולא נערכים ביד: תיקון עושים ב-`src/` (או במקור שב-`assets/`) ובונים מחדש. בדף יש `<base href="/">`, ולכן כל הנתיבים בו יחסיים לשורש ואין בו קישורי `#`.

`next/` היא כתובת התצוגה המקדימה (`noindex`): אותו דף, שטוען את `assets/v2n/` במקום `assets/v2/`, לשינויים שעוד לא עלו לדף הראשי.

`assets/data.js` ו-`assets/fleet-log.js` נכתבים על ידי בוט ב-GitHub Actions (`scripts/update-data.mjs`), פעם אחת לכל נקודת ציון חדשה של אקסודוס — בדרך כלל כל ארבע שעות. יום המרוץ נספר כמו בדוחות הרשמיים: התאריך ב-UTC פחות 6 בספטמבר.

`.github/workflows/probe-tracker.yml` הוא בדיקה חד־פעמית שמוודאת ששרת המעקב עונה לפניות משרתי GitHub Actions. הוא רץ רק כשהוא עצמו משתנה, או בהפעלה ידנית.

## להריץ אצלך

```
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000`. פתיחה בלחיצה כפולה על הקובץ לא תעבוד — הדף צריך שרת. אחרי כל שינוי, לפתוח את הקונסול (F12) ולוודא שאין שגיאות.

להוסיף `?at=2026-09-19T19:25Z` לכתובת כדי לראות את הסצנה בשעה אחרת.

## איך תורמים

- **רעיון או באג:** פתחו Issue. צילום מסך ודגם הטלפון עוזרים יותר מכל תיאור.
- **קוד:** Fork, ענף, ו-Pull Request קטן שעושה דבר אחד.
- **הכי מבורך:** ביצועים בטלפונים חלשים, נגישות, RTL ותאימות לספארי.
- **לא דרך Pull Request:** `data.js` מתעדכן אוטומטית בכל נקודת ציון, ו-`deep-dive.html` והטקסטים בעברית פעמיים ביום; שינוי בהם יתנגש בעדכון הבא. טעות במספר או בניסוח? Issue עדיף.

בלי עוגיות ובלי מעקב אישי אחרי גולשים: מספר הביקורים נספר ב-Cloudflare Web Analytics, בלי עוגיות ובמספרים מצרפיים בלבד. שינוי שמוסיף עוגיה או מעקב אישי לא ייכנס.
