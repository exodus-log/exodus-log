# יומן אקסודוס

יומן עצמאי בעברית שעוקב אחרי דניאל פינסקי והסירה **אקסודוס** במרוץ **גולדן גלוב 2026**: הקפת העולם לבד, בלי עצירות, בלי GPS ובלי עזרה מבחוץ.

זה פרויקט של אוהדים, לא אתר רשמי של המרוץ ולא של הצוות של דניאל. המספרים הם תמונת מצב מהעדכון האחרון, לא שידור חי. המקורות הרשמיים הם [מעקב המרוץ של YB](https://pro.yb.tl/ggr2026/) ו[הדיווחים היומיים של המרוץ](https://goldengloberace.com/).

**האתר:** [exodus-log.com](https://exodus-log.com)

## איך זה בנוי

אתר סטטי: HTML, CSS ו-JavaScript רגילים, בלי שלב בנייה ובלי שרת. כל דחיפה ל-`main` עולה לאוויר לבד.

| קובץ | מה יש בו |
|---|---|
| `index.html` | הדף הראשי: ההדמיה, שושנת הרוחות, הגלובוס והמקטעים שמתחת |
| `next/index.html` | הגרסה הבאה של הדף הראשי: ההדמיה כחלון קבוע על כל המסך. ראו למטה |
| `deep-dive.html` | הניתוח המלא, סטטי לגמרי, בלי JavaScript |
| `assets/data.js` | כל המספרים: מיקום, דירוג, צי, מסלול, מזג אוויר, ונקודת החובה הבאה |
| `assets/front.js` | מרנדר את הדף הראשי מתוך `data.js`, וטוען בעצלתיים את הגלובוס והסקסטנט |
| `assets/deck.js` | סצנת הסיפון: WebGL, אסטרונומיה, גלים, רוח וזרם |
| `assets/rose.js` | שושנת הרוחות. גם מציגה את התנאים וגם מסובבת את המצלמה |
| `assets/globe.js` | הגלובוס והמפה (MapLibre), פס הזמן וניגון המסע |
| `assets/sextant.js` | צעצוע הסקסטנט: מדידת גובה השמש וקו מיקום |
| `assets/course.js` | נאפה פעם אחת: קו המסלול הרשמי, נקודות החובה, והיסטוריית הצי מהזינוק |
| `assets/geo/land50.js` | קו החוף העולמי, Natural Earth 1:50m |
| `assets/tiles/earth/` | כדור הארץ: NASA Blue Marble, אריחים מקומיים |
| `assets/vendor/` | MapLibre GL JS, עותק מקומי |
| `assets/fonts/` | הפונטים, תת-קבוצה עברית ולטינית |
| `assets/front.css` | העיצוב של הדף הראשי |
| `assets/v2/` | הקבצים של הגרסה במסך מלא: המנוע, שורת הנתונים והתפריט, "המסע", וקו חוף למפה הקטנה |
| `assets/icons/`, `manifest.webmanifest` | הוספה למסך הבית, כמו אפליקציה |
| `assets/style.css` | העיצוב של `deep-dive.html` |

שלושה כללים לפני שנוגעים בקוד:

- **אין בדף הראשי מספר שכתוב ביד.** כל מספר מגיע מ-`data.js`.
- **אין שום תלות חיצונית.** בלי CDN, בלי פונט מגוגל, בלי שרת אריחים. הדף פונה רק לדומיין של עצמו.
- **סדר הטעינה קבוע:** `data.js`, אחריו `course.js`, ואז `deck.js`, `rose.js` ו-`front.js` עם `defer`.

`assets/app.js` ו-`assets/geo.js` הם המנוע של הגרסה הקודמת של הדף הראשי. הם כבר לא נטענים בשום מקום.

## הגרסה במסך מלא

ב-[exodus-log.com/next](https://exodus-log.com/next/) רצה הגרסה הבאה של הדף הראשי, על אותו `data.js`. ההדמיה היא חלון קבוע על כל המסך, כדי שגרירה באצבע תוכל להטות את המבט לכל כיוון, גם אל מתחת למים. הטקסט יושב ישר על התמונה: שורת נתונים, שלושה שעונים, מספרי המרוץ, ומפה קטנה שפותחת את "המסע" (הגלובוס, הצי, התחזית והסקסטנט) מעל החלון. על המים שוכבת טבעת מצפן של שנתות, עם נוצת רוח, חץ זרם וקשתות גל.

שני קבצים ב-`assets/v2/` נבנים אוטומטית ולא נערכים ביד: `deck.js` נבנה מ-`assets/deck.js` ועוד תוספות, ו-`journey.js` נבנה מ-`assets/front.js`. גם `globe.js` ו-`sextant.js` שם הם העתקים של המקור בצבעים אחרים. תיקון באחד מהם עושים במקור.

`.github/workflows/probe-tracker.yml` הוא בדיקה חד־פעמית שמוודאת ששרת המעקב עונה לפניות משרתי GitHub Actions. הוא רץ רק כשהוא עצמו משתנה, או בהפעלה ידנית.

## להריץ אצלך

```
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000`. פתיחה בלחיצה כפולה על הקובץ לא תעבוד — הגלובוס צריך שרת. אחרי כל שינוי, לפתוח את הקונסול (F12) ולוודא שאין שגיאות.

להוסיף `?at=2026-09-19T19:25Z` לכתובת כדי לראות את הסצנה בשעה אחרת.

- **לא דרך Pull Request:** `data.js`, `deep-dive.html` והטקסטים בעברית מתעדכנים כאן פעמיים ביום, ושינוי בהם יתנגש בעדכון הבא. טעות במספר או בניסוח? Issue עדיף.
