# יומן אקסודוס

יומן עצמאי בעברית שעוקב אחרי דניאל פינסקי והסירה **אקסודוס** במרוץ **גולדן גלוב 2026**: הקפת העולם לבד, בלי עצירות, בלי GPS ובלי עזרה מבחוץ.

זה פרויקט של אוהדים, לא אתר רשמי של המרוץ ולא של הצוות של דניאל. המספרים הם תמונת מצב מהעדכון האחרון, לא שידור חי. המקורות הרשמיים הם [מעקב המרוץ של YB](https://pro.yb.tl/ggr2026/) ו[הדיווחים היומיים של המרוץ](https://goldengloberace.com/).

**האתר:** [exodus-log.com](https://exodus-log.com)

## איך זה בנוי

אתר סטטי: HTML, CSS ו-JavaScript רגילים, בלי שלב בנייה ובלי שרת. כל דחיפה ל-`main` עולה לאוויר לבד.

| קובץ | מה יש בו |
|---|---|
| `index.html` | הדף הראשי: ההדמיה, שורת המספרים, הכרטיסים |
| `deep-dive.html` | הניתוח המלא, סטטי לגמרי |
| `assets/data.js` | כל המספרים: מיקום, דירוג, צי, מסלול, מזג אוויר |
| `assets/front.js` | מרנדר את הדף הראשי מתוך `data.js` |
| `assets/app.js` | מנוע ההדמיה: WebGL, אסטרונומיה, גלים, מפה |
| `assets/geo.js` | קו החוף, קו הזינוק והשערים. לא משתנה |
| `assets/style.css` | העיצוב של שני הדפים |

שני כללים לפני שנוגעים בקוד:

- **אין בדף הראשי מספר שכתוב ביד.** כל מספר מגיע מ-`data.js`.
- **סדר הטעינה קבוע:** `data.js`, אחריו `geo.js`, אחריו `app.js`, ובסוף `front.js`. שני הראשונים מגדירים משתנים ששני האחרונים צורכים.

## להריץ אצלך

```
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000`. אחרי כל שינוי במנוע, לפתוח את הקונסול (F12) ולוודא שאין שגיאות.
