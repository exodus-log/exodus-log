# הדף הראשי החדש — תצוגה מקדימה

התיקייה הזאת היא הדף הראשי החדש של יומן אקסודוס. היא חיה בכתובת `/next/` ולא נוגעת בדף הקיים:
`index.html`, `app.js`, `front.js` ו-`style.css` שבשורש נשארו בדיוק כמו שהיו.

כל המספרים מגיעים מ-`../assets/data.js`, אותו קובץ שהרענון כותב פעמיים ביום. אין כאן מספר שכתוב ביד.

## מה יש כאן

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | המבנה, וה-CSS הקריטי של המסך הראשון בתוך הדף |
| `assets/front.css` | כל שאר העיצוב. נטען בלי לחסום את הפריים הראשון |
| `assets/deck.js` | סצנת הסיפון (WebGL). נגזר מ-`app.js` הישן: הסצנה ממלאת את המסך, החיצים המרחפים ירדו, הרוח באוויר, הגל הוא פני המים, הזרם מתחתם |
| `assets/rose.js` | שושנת הרוחות, SVG. גם מציגה וגם מסובבת את המצלמה |
| `assets/front.js` | שורת המספרים, פס הצי, כרטיסי קנה המידה, התחזית, היום של דניאל, וטעינה עצלה של הגלובוס והסקסטנט |
| `assets/globe.js` | הגלובוס והמפה (MapLibre, הטלת globe), פס הזמן וניגון המסע |
| `assets/sextant.js` | צעצוע הסקסטנט |
| `assets/course.js` | נאפה פעם אחת: קו המסלול הרשמי, נקודות החובה, והיסטוריית הצי מהזינוק |
| `assets/geo/land50.js` | קו החוף העולמי, Natural Earth 1:50m |
| `assets/tiles/earth/` | כדור הארץ: NASA Blue Marble, 85 אריחים, זום 0–3 |
| `assets/vendor/` | MapLibre GL JS 5.24, עותק מקומי |
| `assets/fonts/` | שלוש משפחות הפונטים, תת-קבוצה עברית ולטינית |

אין סקריפט חיצוני אחד, אין פונט חיצוני ואין אריח חיצוני. הדף לא פונה לשום שרת חוץ מהדומיין שלו.

## להריץ אצלך

מתיקיית השורש של הפרויקט:

```
python -m http.server 8000
```

ואז `http://localhost:8000/next/`. פתיחה בלחיצה כפולה על הקובץ לא תעבוד: הגלובוס צריך שרת.

`?at=2026-09-19T19:20Z` בסוף הכתובת מציג את הסצנה בשעה אחרת (שקיעה, לילה). בלי הפרמטר: השעה האמיתית.

## להפוך אותו לדף הראשי

1. להעביר את התוכן של `next/` לשורש, ואת `next/assets/*` לתוך `assets/`.
2. ב-`index.html` החדש: `../assets/data.js` הופך ל-`assets/data.js`, ו-`../deep-dive.html` ל-`deep-dive.html` (שלוש הופעות).
3. למחוק את שורת ה-`robots noindex`.
4. `app.js`, `front.js` הישן, `geo.js` ו-`style.css` נשארים: `deep-dive.html` עדיין משתמש ב-`style.css`.

## מה נאפה ומה חי

- **חי, מ-`data.js`:** מיקום, דירוג, צי, מסלול, תנאי ים, משפט הכותרת.
- **חי, מחושב בדפדפן:** שמש, ירח, כוכבים, קו היום והלילה, מעגלי הסקסטנט.
- **נאפה:** `course.js`. היסטוריית הצי בו נגמרת ב-19.9; מה שקרה אחריה מושלם אוטומטית מ-`FLEET` ומ-`TRACKP`, בקו ישר. כדי שפס הזמן יישאר מדויק לאורך חודשים כדאי לאפות אותו מחדש מדי פעם מקובץ המעקב.
